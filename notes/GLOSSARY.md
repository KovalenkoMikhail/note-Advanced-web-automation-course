## A

**AAAA-Record** - DNS record for IPv6 addresses

**ACID** - Database transaction properties: Atomicity, Consistency, Isolation, Durability

**Ad-hoc Testing** - Informal testing without formal test cases

**Agent** - In Jenkins, defines where pipeline will execute

**AMQP** - Advanced Message Queuing Protocol (used by RabbitMQ)

**A-record** - DNS record linking domain name with IPv4 address

**API** - Application Programming Interface

**Arrow Functions** - JavaScript functions using => syntax

**Assertor Tunnels** - Methods for testing exceptions in code

**Authorization** - Process of granting access to resources

**Automated Tests** - Tests that run automatically without manual intervention

---

## B

**BASE** - NoSQL database principles: Basically Available, Soft State, Eventually Consistent

**Bearer Authentication** - Authentication method using tokens (JWT)

**Binary Data** - Data represented in binary format (0s and 1s)

**Binding** - In RabbitMQ, rules that connect exchange and queue

**Block Elements** - HTML elements that occupy full width (div, p, h1)

**Boundary Value Analysis** - Test design technique testing limits of input ranges

**Bug Report** - Document describing software defect with reproduction steps

**Build** - Compiled version of software ready for deployment

---

## C

**Cache** - Temporary storage for frequently accessed data

**Cache-Control** - HTTP header controlling caching behavior

**CD** - Continuous Delivery/Deployment

**Channel** - In RabbitMQ, virtual connection for performing operations

**Cherry-pick** - Git command to apply specific commit to another branch

**CI** - Continuous Integration

**Closures** - JavaScript functions with access to outer function variables

**CNAME-record** - DNS record creating alias for domain

**Collection** - In Postman, group of API requests

**Comparison Operators** - MongoDB operators for comparing values ($eq, $ne, $gte, $lte, $gt, $lt)

**Connection** - TCP connection to service (e.g., RabbitMQ)

**Consumer** - In message broker, component that receives messages

**Content-Type** - HTTP header specifying media type of resource

**Cookie** - Small data fragment stored by browser for session management

**CSRF** - Cross-Site Request Forgery attack

**CSS Selectors** - Patterns for selecting HTML elements

---

## D

**Data-Driven Testing** - Testing approach using external data sources

**DB Logs** - Database logs containing queries, transactions, and errors

**Deadlock** - Situation where two or more processes cannot proceed

**Dead Letter Queue (DLQ)** - Queue for messages that failed processing

**Detached HEAD** - Git state where HEAD points to commit, not branch

**dig** - DNS lookup utility (more powerful than nslookup)

**DNS** - Domain Name System, converts domain names to IP addresses

**Docker** - Platform for containerizing applications

**Dynamic Testing** - Testing performed by executing code

---

## E

**Endpoint** - Specific URL for accessing API resource

**Equivalence Partitioning** - Test design dividing inputs into valid/invalid groups

**Error Guessing** - Test design based on tester's experience

**Exception** - Error condition during program execution

**Exchange** - In RabbitMQ, receives messages and routes to queues

**Exploratory Testing** - Testing approach based on tester experience

**EXPOSE** - Docker command to expose port for connections

---

## F

**Failover** - Switching to backup system when primary fails

**Fetch API** - Modern JavaScript API for HTTP requests

**Flow Control** - TCP mechanism managing data sending speed

**forEach** - JavaScript method for iterating arrays

**for...in** - JavaScript loop iterating object keys/array indices

**for...of** - JavaScript loop iterating array values

**FTP** - File Transfer Protocol

**Functional Testing** - Testing what system does and its functions

---

## G

**GET** - HTTP method for retrieving resources

**Git** - Distributed version control system

**Git Flow** - Branching model for Git repositories

**Grafana** - Monitoring and visualization platform

**GUI Test** - Testing of Graphical User Interface

---

## H

**HAR Archive** - HTTP Archive format for logging HTTP transactions

**HATEOAS** - Hypermedia as the Engine of Application State

**HEAD** - HTTP method like GET but without response body

**Head of Line Blocking** - When one blocked request delays others

**Headers** - Metadata sent with HTTP requests/responses

**Hook** - Git scripts that run automatically at certain points

**Horizontal Scaling** - Adding more servers to handle load

**Hotfix** - Urgent fix for production bug

**HTTP** - Hypertext Transfer Protocol

**HTTP/1** - First version of HTTP protocol

**HTTP/2** - Improved version with multiplexing

**HTTP/3** - Latest version using QUIC over UDP

## I

**ICMP** - Internet Control Message Protocol

**Image** - In Docker, template for creating containers

**IndexedDB** - Browser API for storing large amounts of data

**Inline Elements** - HTML elements occupying only necessary space (span, a, img)

**Integration Testing** - Testing interaction between components

**IP** - Internet Protocol

**IPsec** - Internet Protocol Security

**ISP** - Internet Service Provider

**Jenkins** - CI/CD automation server

**JMeter** - Performance testing tool

**JSON** - JavaScript Object Notation

## K

## M

**Maven** - Build automation tool for Java projects

**Message** - In RabbitMQ, data sent between publisher and consumer

**Message Broker** - Intermediary for transmitting messages between applications

**Mock** - Test double simulating real object behavior

## Git Commands Quick Reference

```bash
# Repository Setup
git init                    # Initialize repository
git clone <url>             # Clone repository
git remote -v               # List remote repositories

# Basic Operations
git status                  # Check status
git add .                   # Stage all changes
git commit -m "message"     # Commit changes
git push origin <branch>    # Push to remote
git pull                    # Pull and merge changes
git fetch                   # Download changes without merging

# Branching
git branch                  # List branches
git branch <name>           # Create branch
git checkout <name>         # Switch branch
git checkout -b <name>      # Create and switch branch
git merge <branch>          # Merge branch
git branch -d <name>        # Delete branch

# Advanced
git stash                   # Save uncommitted changes
git stash pop               # Restore stashed changes
git rebase <branch>         # Rebase commits
git cherry-pick <commit>    # Apply specific commit
git bisect                  # Binary search for bug
git tag -a v1.0.0           # Create annotated tag
git reflog                  # View reference log
```

## Linux Commands Quick Reference

```bash
# Navigation
pwd                         # Print working directory
ls                          # List files
ls -la                      # List all with details
cd <directory>              # Change directory
cd ..                       # Go up one level
cd -                        # Return to previous directory

# File Operations
touch <file>                # Create file
rm <file>                   # Remove file
rm -rf <directory>          # Force remove directory recursively
cp <source> <dest>          # Copy
mv <source> <dest>          # Move/rename
mkdir <directory>           # Create directory
rmdir <directory>           # Remove empty directory

# File Search
find . -name "pattern"      # Find files
grep "text" <file>          # Search text in file

# File Viewing/Editing
cat <file>                  # Display file content
nano <file>                 # Edit file with nano
vim <file>                  # Edit file with vim
less <file>                 # View file page by page

# File Analysis
wc -l <file>                # Count lines
wc -w <file>                # Count words
wc -m <file>                # Count characters
diff <file1> <file2>        # Compare files

# System
echo "text"                 # Print text
sudo <command>              # Run as superuser
```

## Docker Commands Quick Reference

```bash
# Container Management
docker ps                   # List running containers
docker ps -a                # List all containers
docker start <container>    # Start container
docker stop <container>     # Stop container
docker restart <container>  # Restart container
docker rm <container>       # Remove container

# Container Creation
docker run <image>          # Run container from image
docker run -d <image>       # Run in detached mode
docker run -p 8080:80       # Map port 80 to 8080
docker run --name <name>    # Name container

# Container Interaction
docker exec -it <container> <command>  # Execute command in container
docker logs <container>     # View container logs

# Images
docker images               # List images
docker pull <image>         # Pull image from registry
docker build -t <name> .    # Build image from Dockerfile
docker rmi <image>          # Remove image
```

## HTTP Status Codes

**2xx Success:**
- 200 OK - Request succeeded
- 201 Created - Resource created
- 204 No Content - Success but no content to return

**3xx Redirection:**
- 301 Moved Permanently - Resource permanently moved
- 302 Found - Temporary redirect
- 304 Not Modified - Cached version still valid

**4xx Client Errors:**
- 400 Bad Request - Invalid syntax
- 401 Unauthorized - Authentication required
- 403 Forbidden - Access denied
- 404 Not Found - Resource not found
- 429 Too Many Requests - Rate limit exceeded

**5xx Server Errors:**
- 500 Internal Server Error - Generic server error
- 502 Bad Gateway - Invalid response from upstream
- 503 Service Unavailable - Service temporarily unavailable
- 504 Gateway Timeout - Upstream timeout
