## 24. Dead Letter Queue (DLQ)

### Описание DLQ:

- **Dead Letter Queue** - очередь для сообщений, которые не удалось обработать
- **Назначение** - изоляция проблемных сообщений для анализа и повторной обработки

### Условия попадания в DLQ:

1. **Истечение времени обработки** - "Failed to process message 5 min"
2. **Time to Live (TTL)** - если за время жизни сообщения не дан ответ - падает в DLQ
3. **Ошибки обработки** - сообщения, которые не удалось обработать

### Схема работы:

```
Invoices Q → [Failed to process] → DLQ
     ↓
Subscribe to invoices
     ↓
[No response in TTL] → DLQ
```

## 25. RabbitMQ - брокер сообщений

### Описание RabbitMQ:

- **Брокер сообщений/посредник**
- **Работающий по протоколу AMQP** (Advanced Message Queuing Protocol)
- **Для асинхронной передачи message между приложениями и сервисами**
- **Надежная доставка, гибкая маршрутизация и масштабируемость**

### Ключевые компоненты:

1. **Publisher** - создает сообщение
2. **Connection** - TCP соединение с RabbitMQ
3. **Channel** - все действия происходят через этот канал
4. **Message** - отправка на exchange, содержит routing key
5. **Exchange (обменник)** - получает message с ключом и решает в какую очередь отправить
6. **Binding** - правила по которым соединяются exchange и queue
7. **Queue** - очередь сообщений
8. **Consumer** - получатель сообщений

## 29. SSH - безопасное подключение

### Описание SSH:

- **Network management protocol** для безопасного подключения к удаленным системам
- **Зашифрованный канал** для управления

### Команды:

- **Подключение:** `ssh user@hostname_02_ip`
- **Копирование файлов:** `scp file.txt user@host:path`
- **Генерация ключей:** `ssh-keygen`

### SSH Keys:

- **Почему SSH ключи безопаснее паролей?**
- **Harder to guess, longer, and more reliable**

### SSH Agent:

- **Инструмент для кэширования пароля ключа**

### Port Forwarding:

- **Network traffic redirection**
- **Пример:** подключение к БД или веб-интерфейсу только на localhost удаленного сервера

### SSH Tunneling:

- **Способ создания зашифрованного канала**
- **Для передачи данных между двумя машинами**
- **Позволяет безопасную передачу трафика**

### Ограничение доступа SSH:

- **Настройка sshd_config**
- **Отключение паролей:** `PasswordAuthentication no`
- **Доступ только для определенных пользователей:** `AllowUsers`

## 30. JavaScript Functions Advanced

### Описание:

- **Продвинутые концепции функций** - анонимные функции, замыкания, контекст
- **Функциональное программирование** - чистые функции и стиль разработки

### Анонимные функции:

#### Определение:

- **Объявляются без имени или идентификатора** - function() {}
- **Стрелочные функции всегда анонимные** - () => {}
- **Function() конструкторы создают анонимные функции** - new Function()

#### Особенности:

- **Не могут легко вызывать себя рекурсивно** - нет имени для рекурсии
- **Присваиваются переменной** - const greet = function() {}

### Стрелочные функции vs Обычные функции:

#### Стрелочные функции:

- **Используют синтаксис =>** - более короткий синтаксис
- **Всегда анонимные** - не имеют собственного имени
- **Не имеют собственного this** - наследуют контекст
- **Не имеют arguments, super, new.target** - ограниченная функциональность

#### Пример:

```javascript
const a1 = a.map((s) => s.length);
```

### Замыкания (Closures):

#### Определение:

- **Комбинация функции** - объединенная вместе
- **С ссылками на окружающее состояние** - лексическое окружение
- **Доступ к переменным внешней функции** - из внутренней функции

#### Пример:

```javascript
function init() {
  var name = 'Mozilla';
  function displayName() {
    console.log(name); // Доступ к переменной внешней функции
  }
  displayName();
}
init(); // "Mozilla"
```

### Контекст this:

#### Потеря контекста:

- **Извлечение метода из объекта** - когда метод присваивается переменной
- **Передача как аргумент** - в другую функцию
- **Внутри функций** - создается новая область видимости
- **С колбэками** - this меняется
- **После async/await или setTimeout** - асинхронный контекст

#### Предотвращение потери контекста:

- **Использовать стрелочные функции** - сохраняют контекст
- **Использовать bind()** - привязка контекста
- **Сохранить this в переменной** - const self = this

### Функциональное программирование:

#### Чистые функции:

- **При одинаковом входе** - одинаковый выход
- **Делают код тестируемым** - предсказуемое поведение
- **Предсказуемые** - без побочных эффектов

#### Стиль разработки:

- **Стиль построения программного обеспечения** - функциональный подход
- **Использование функций как основных строительных блоков** - композиция функций

## 31. JavaScript Iteration Methods

### Описание:

- **Методы итерации** - способы перебора массивов и объектов
- **forEach, for...in, for...of** - различные подходы к итерации

### forEach:

#### Основное использование:

```javascript
let array1 = [1, 2, 3, 4, 5];
array1.forEach(function (item) {
  console.log(item); // 1,2,3,4,5
});
```

#### С параметрами:

```javascript
array1.forEach(function (item, index, array) {
  console.log('a[' + index + ']=' + item);
});
// a[0]=1, a[1]=2, a[2]=3, a[3]=4, a[4]=5
```

#### Особенности:

- **Принимает функцию обратного вызова** - определяет операции для каждого элемента
- **Неопределенные элементы не отображаются** - пропускает пустые слоты
- **Можно использовать с условиями** - if внутри forEach

### for...in:

#### Для объектов:

```javascript
for (let key in person) {
  console.log(`${key}:${person[key]}`);
}
```

#### Для массивов:

```javascript
let arr = ['a', 'b'];
for (let i in arr) {
  console.log(i, arr[i]); // 0 a, 1 b
}
```

#### Особенности:

- **Просматривает объект (ключи/имена)** - перечисляет свойства
- **Используется для перечисления свойств объекта** - итерация по ключам

### for...of:

#### Использование:

```javascript
const items = ['phone', 'table'];
for (const item of items) {
  console.log(item); // phone, table
}
```

#### Особенности:

- **Итерация по массивам, массивоподобным объектам** - sets, maps и т.д.
- **Просматривает массив | значения (элементы)** - итерация по значениям
- **Более современный подход** - ES6+ синтаксис

### Сравнение методов:

| Метод    | Назначение          | Что итерирует       |
| -------- | ------------------- | ------------------- |
| forEach  | Массивы             | Элементы с индексом |
| for...in | Объекты/массивы     | Ключи/индексы       |
| for...of | Итерируемые объекты | Значения            |
